# Hakimi World News Broadsheet — 26 November 2026

An original editorial broadsheet (`1024×1024`) summarizing the verified global news of **Thursday, 26 November 2026** for the `make.fun` `news-image-20261126` competition.

## Run

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Deterministically writes the `1024×1024` broadsheet image to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png` inside the grader container) using Node 22 standard library only.
